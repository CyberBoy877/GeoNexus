🌍 GeoNexus

Explore the World. Discover Everything.

GeoNexus is an interactive geographic exploration platform designed to let users explore countries, states, provinces, territories, and other administrative regions around the world through an interactive map.

🚀 Features

- 🌍 Interactive world map
- 🗺️ Explore countries and regions
- 🔍 Search for locations
- 📍 Clickable geographic regions
- 🏳️ Country information
- 🏛️ States, provinces, and territories
- 📊 Geographic data and statistics
- 📱 Responsive interface

🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- SVG
- JSON
- GitHub Pages

📌 Project Status

Development — Initial Stage

The project is currently being developed, starting with the basic interactive world map. More geographic data and features will be added progressively.

🎯 Future Plans

- Country → State/Province navigation
- State/Province → District-level exploration
- Advanced search
- Geographic statistics
- Continent-based filtering
- Interactive quizzes
- Dark mode
- Improved mobile experience

🌐 Deployment

GeoNexus is designed to be hosted using GitHub Pages.
